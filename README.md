# Why doesn't your optimizer go downhill?

An interactive explainer showing how gradient descent, momentum and Adam each step in a different direction on the same loss landscape, and how simply rotating the valley turns Adam from the fastest into one of the slowest.

**Live:** https://kanikasure.github.io/optimizer-explainer/ · To run locally, serve the folder (e.g. `python -m http.server`) and open `index.html`.
